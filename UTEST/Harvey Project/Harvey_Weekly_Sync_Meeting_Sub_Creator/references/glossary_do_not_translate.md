# Glossary — terms that stay in English

Harvey.AI weekly FN sync meetings are dense with product names, UI labels,
and platform/tooling nouns. Translate the surrounding Vietnamese naturally
and conversationally, but **keep these as-is** (no Vietnamese gloss, no
parenthetical translation needed once a term has appeared once in a given
video — a first-mention gloss like `suggestion card (thẻ gợi ý)` is fine,
but don't repeat it every cue).

This list is a *starting point from meetings seen so far*, not exhaustive —
new Harvey features will introduce new terms. The rule, not just the list,
is what matters: **product/feature names, UI element and button labels,
file formats, and technical nouns stay in English; ordinary descriptive
language around them is translated.**

## Harvey.AI product/feature names
- Assistant Thread
- Contract Intelligence
- Harvey (the product name, and "Harvey" as the AI agent's name in dialogue)
- add-in (the Word/Outlook add-in itself)
- chips (clickable prompt shortcuts in the add-in chat)
- suggestion card / card
- banner

## UI actions / button labels (keep the exact label)
- Run Agent
- Continue in Word
- Create Invite
- Apply Changes
- Apply All / Apply All with Comments
- Accept / Reject (when naming the actual action on a suggestion card —
  "chấp nhận"/"từ chối" is fine as a gloss alongside it)
- Summarize this meeting
- Discard

## Platform / file / tooling nouns
- Word, Outlook (Microsoft product names)
- pane / panel (the add-in's side panel in the host app)
- redline, counterparty (standard contract-review jargon; "đối tác" is an
  acceptable gloss for counterparty but keep the English term visible at
  least once)
- test case, test cycle (uTest terminology — never "trường hợp kiểm thử")
- intake email
- agenda (when it's the literal meeting-agenda feature/field)
- flag (feature flag)

## People's names, product test-account emails, dates/times
Never translate or alter: tester/speaker names, email addresses
(`test@harvey.ai`), exact dates and times, bug/ticket IDs, numeric counts
("136 suggestion cards").

## When unsure

If a new term could plausibly be a Harvey feature name (capitalized,
repeated, clearly referring to a specific UI element) rather than ordinary
English, default to keeping it in English and flag it in the meeting
analysis write-up (Step 6) so the user can confirm or correct it for next
time — don't guess a Vietnamese equivalent for something that might be a
proper feature name.
